# Changelog

## B2 - November 23, 2026

- Retained B1 USB ConfigFS networking options.
- Enabled Atheros ATH9K_HTC support.
- Enabled Ralink RT2800USB support.
- Enabled MediaTek MT76x2U support.
- Preserved the original Motorola hardware configuration.
- Successfully compiled Linux 5.4.302-moto.
- Validated boot, Android hardware, Magisk, and Kali NetHunter.
- Validated wired and wireless KeX desktop access.
- Validated Burp Suite HTTP/HTTPS proxy and Repeater.

### Known limitations

- External USB wireless adapters not yet tested.
- Monitor mode and packet injection not yet validated.
- USB HID capabilities not yet validated.
- No public flashable boot image provided.
