## B1/B2 development

This repository documents independently tested configuration
iterations built using the upstream project.

B1 enabled USB ConfigFS networking features.

B2 retained those features and enabled selected external
USB wireless drivers.

The original upstream project and its contributors retain
credit for their respective work.

This repository is an experimental configuration and
validation project, not an official Kali NetHunter release.
